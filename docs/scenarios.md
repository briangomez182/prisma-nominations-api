# Escenarios E1–E10: matriz de trazabilidad

Cada escenario obligatorio del enunciado, con el resultado esperado, cómo lo resuelve el diseño (decisiones
`Dn` del [README](../README.md#decisiones-de-arquitectura)), los tests que lo evidencian y cómo mostrarlo en la
demo.

## Cómo correr un escenario

Los tests están etiquetados con JUnit 5 `@Tag("E1")` … `@Tag("E10")` (un test puede tener varias etiquetas) y
`@Tag("integration")` los que levantan Spring + Testcontainers. Surefire toma `-Dgroups` / `-DexcludedGroups`
sin configuración extra en el `pom.xml`. Los de integración requieren Docker corriendo.

```bash
cd app
mvn test -Dgroups=E6                          # un escenario (unitarios + integración)
mvn test -Dgroups='E4 | E5 | E7'              # varios (expresión de tags de JUnit 5)
mvn test -Dgroups='E9 & integration'          # solo la evidencia de integración de E9
mvn test -DexcludedGroups=integration         # solo unitarios (sin Docker, segundos)
mvn test                                      # suite completa
```

## Demo manual: preparación

```bash
TOKEN=$(scripts/mint-token.sh ENT01)                       # canal de la entidad ENT01 (write + read)
OPERATOR=$(scripts/mint-token.sh "" nominations:operate)  # /internal/** (reproceso)

nominate() {  # nominate <card_id> [request_id] [correlation_id]
  curl -s -i -X POST http://localhost:8080/v1/nominations \
    -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
    -H "X-Correlation-Id: ${3:-demo-$(uuidgen)}" \
    -d "{\"request_id\":\"${2:-$(uuidgen)}\",\"customer_id\":\"CUST-000123\",
         \"account_id\":\"0001234567890987654\",\"card_id\":\"$1\",\"alias\":\"CUENTA SUELDO\"}"
}
```

El simulador de ABM elige el comportamiento por el `card_id` (contiene `FAIL`, `SLOW`, `SILENT`, `DUP` o
`REJECT[_NNN]`; sin marca aprueba). Detalle en [abm-mock.md](abm-mock.md).

Pantallas: Swagger http://localhost:8080/swagger-ui.html · Kafka UI http://localhost:8081 ·
Jaeger http://localhost:16686 · Grafana http://localhost:3000 · Prometheus http://localhost:9090/alerts.

## Notas

- El mapa de tags es la fuente de verdad del conteo: `mvn test -Dgroups=E<n>` corre exactamente la evidencia de
  la columna "Tests" (más los unitarios marcados).
- Los tests de integración de E9 usan el id del listener `notifications-demo` (`KafkaListenerEndpointRegistry`)
  para detener y arrancar el consumidor sin tocar código de producción.
