# prisma-nominations-api
Solución de nominación de cuentas y tarjetas para una entidad financiera, creada con Java 21 y Spring Boot 3. APIs REST, arquitectura hexagonal, procesamiento asíncrono con Kafka, persistencia transaccional, idempotencia y patrón Transactional Outbox. Integración simulada con ABM, gestión de estados, auditoría, seguridad con OAuth2, observabilidad.
